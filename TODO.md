## Персональная ссылка

Используйте хеш: `https://ваш-домен/#anna` или `https://ваш-домен/#id=anna`.
Список гостей находится в `src/data/guests.js`; ключ слева — это `id` из ссылки.

## Учёт ответов без бэкенда

Создайте Google Form и вставьте её предзаполненную ссылку в `rsvpFormUrl` в `src/data/guests.js`.
Ответы гостей автоматически попадут в связанную с формой Google Sheet. Для связи ответа с гостем добавьте в форму поле `id` и подставьте для него `{id}` в ссылке.

## GitHub Pages

После первого push в GitHub откройте **Settings → Pages** репозитория и в поле **Source** выберите **GitHub Actions**. Затем каждый push в ветку `main` будет автоматически публиковать сайт.
